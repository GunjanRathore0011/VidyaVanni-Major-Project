# 📘 Vidyavanni – AI Powered Learning Platform

**Vidyavanni** is an AI-powered platform designed to help students prepare for technical interviews and analyze GitHub repositories intelligently.  
The platform provides **AI-driven mock interviews** and **repository insights** to improve learning and coding skills.

🔗 **Live Demo**  https://vidyavanni-major-project-1.onrender.com

---

## 🚀 Features

### 🎤 AI Mock Interview Practice
- Practice technical interviews with AI  
- AI-generated interview questions  
- Instant feedback and evaluation  
- Improve confidence and communication skills  

### 📊 Git Repository Insights
- Analyze GitHub repositories easily  
- AI-generated summaries of repositories  
- Understand project structure quickly  
- Helps developers explore unfamiliar codebases  

---

## 🛠️ Tech Stack

- **Frontend:** React.js / Next.js  
- **Backend:** Node.js, Express.js  
- **AI Integration:** Generative AI APIs  
- **Database:** MongoDB  
- **Deployment:** Vercel / Render
